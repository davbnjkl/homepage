# 杂鱼种族鱼卡图鉴

这个文件记录当前归属“杂鱼种族”的基础通用鱼卡。后续如果某张鱼被划入新种族，应从这里移到对应种族文档。

## 公共说明

- 种族：杂鱼种族
- 流派：无
- 标签：无
- 每日自然成长：1
- 杂鱼种族主要承担通用工具效果，例如金币、售价、钓鱼费用、鱼获选择数量和单卡成长。
