# 大钓鱼鱼鱼卡图鉴

这个文档作为鱼卡设计的主文档。之后新增鱼卡、调整数值、改效果，优先改这里，再同步到 `game-data.js` 和 `card-effects.js`。

## 游戏玩法概括

《大钓鱼鱼》是一款以“钓鱼三选一、水族馆养成、鱼卡合成、三日结算”为核心循环的肉鸽卡牌游戏。玩家每局从第 1 天开始经营水族馆，通过花费金币钓鱼获得鱼卡，再选择鱼卡放入水族馆格子中，让鱼卡通过自身效果、星级、流派联动和每日成长不断提高价值。

当前基础循环：

1. 玩家花费金币进行一次钓鱼。
2. 每次钓鱼会出现 3 张鱼卡，玩家通常选择其中 1 张。
3. 被选择的鱼卡需要放入水族馆的已解锁格子。
4. 水族馆初始不是 9 格全开，未解锁格子保留位置但不显示。
5. 水族馆内鱼卡位置通常固定，放入后不能随意移动。
6. 鱼卡可以出售换取金币，出售后空出对应格子。
7. 每三张相同鱼卡会自动合成 1 张更高星鱼卡，合成结果保留在第一张卡的位置。
8. 新的一天开始时，水族馆内鱼卡会获得自然成长，并触发各种鱼卡效果。
9. 每第三天结束时进行一次结算，水族馆总价值需要达到目标，否则本轮失败。
10. 每第三天结束后，如果通过结算，会自动获得一次水族馆格子升级选择。

鱼卡设计重点：

- 鱼卡不仅是分数来源，也是主要构筑来源。
- 每张鱼卡都应该有明确流派、触发点和星级成长。
- 鱼卡价值会被自身效果、其他鱼卡效果、角色被动、事件系统和星级共同影响。
- 鱼卡稀有度主要影响出现概率和边框颜色，不直接决定所有强度。
- 三星鱼卡应有更明显的成长价值，部分高稀有三星鱼可以提供特殊机制。
- 所有鱼卡效果应尽量服务于可重复游玩的构筑选择，而不是单次固定最优解。

## 文档格式规范

每张鱼卡建议固定记录这些字段，方便之后直接转成配置：

```text
id：程序用唯一 ID，使用小写英文和短横线。
名称：游戏内显示名称。
流派：流派 ID，例如 school-growth。
稀有度：common / uncommon / rare / epic / legendary / mythic。
基础价值：初始价值。卡面底部显示的是经过效果修正后的当前价值。
基础售价：一般为 1G，特殊鱼可以例外。
占格：默认 1，特殊鱼可为 2 或更高。
标签：用于效果筛选，例如 school、growth、adjacent、combine。
每日自然成长：默认每日自然成长值。大部分鱼可以为 1，特殊鱼可调整。
1星效果：基础效果。
2星效果：通常是数值小幅提高。
3星效果：通常是明显强化，或稀有卡获得额外特殊机制。
触发点：涉及的触发时机，例如 onEnterPond、onDayStart、onCombineResult、modifyCardValue。
```

### 稀有度分布

单个流派目标约 18 张卡，默认分布：

| 稀有度 | 数量 |
| --- | ---: |
| 白 `common` | 2 |
| 绿 `uncommon` | 3 |
| 蓝 `rare` | 4 |
| 紫 `epic` | 4 |
| 橙 `legendary` | 3 |
| 红 `mythic` | 2 |

### 星级设计原则

- 1 星：表达卡牌的基础功能，数值克制。
- 2 星：保留原功能，数值略微提高，尽量不改变操作方式。
- 3 星：给明显成长点。白绿卡可以是更高数值；蓝紫橙红卡可以出现额外联动、范围扩大、触发次数提高或特殊效果。
- 三星鱼卡边框在游戏内显示为彩色，文档里不需要额外标注颜色。

## 流派 001：鱼群共生

流派：`school-growth`

核心关键词：数量积累、同流派联动、相邻收益、入场成长、每日成长、合成滚雪球。

这个流派的目标不是单张鱼爆发，而是让玩家通过铺满水族馆、保留同流派鱼、触发合成，把价值越滚越高。它适合做游戏的第一套完整流派，因为它能让玩家自然理解“水族馆位置”和“卡与卡配合”的意义。

### 流派公共约定

- `school` 指所有 `archetype` 为 `school-growth` 的鱼卡。
- “相邻”默认指上下左右四方向，不含斜角。
- “其他鱼群共生鱼”不包含自身。
- “水族馆已满”指当前已解锁格子全部有鱼。
- 如果某个效果会对所有鱼群共生鱼加价值，默认包含自己，除非文字写明“其他”。

## 初始平衡建议

- 这个流派整体成长偏强，建议先不要给“价值翻倍”效果。
- 大部分售价仍保持 `1G`，避免卖鱼流和价值成长流混在一起导致收益过高。
- 红色和橙色卡可以强，但最好依赖场面条件，例如同流派数量、满水族馆、三星合成。
- 占 2 格鱼卡适合放在紫色和红色，用空间压力换高收益。
- 如果三日结算目标偏低，这个流派会很容易滚过头；可以用每日成长上限、触发次数上限或高稀有度门槛来压制。

## 需要预留或补充的效果能力

这些能力文档里已经用到，但代码里可能还需要逐步补齐：

| 能力 | 用途 |
| --- | --- |
| 按 `archetype` / `tags` 筛选水族馆鱼卡 | 支持所有同流派联动。 |
| 获取上下左右相邻鱼卡 | 支持相邻流派效果。 |
| 记录单卡本日已获得价值 | 支持回游旗鱼等复制成长效果。 |
| 每日触发次数计数 | 支持占潮石斑、密鳞护卫等限制频率。 |
| `onCardValueGain` 事件 | 支持“其他鱼获得价值时我也成长”。 |
| `onCombineResult` 携带合成材料和结果 | 支持合成奖励、三星奖励。 |
| 对单卡或群体增加当前价值的工具函数 | 统一触发日志、动画和贡献统计。 |
| 价值增加动画队列 | 让多张鱼同时成长时不阻塞 UI。 |
