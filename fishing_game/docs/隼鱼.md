# 隼鱼图鉴

这个文件只记录“隼鱼”种族的鱼卡。通用玩法、字段格式和跨种族索引见 [fish-card.md](fish-card.md)。

## 流派 003：高空猎势

流派：`falcon-risk`

核心关键词：高收益、条件负面、猎标、短期爆发、金币风险、价值透支、结算压力。

“隼鱼”是一套偏风险管理的流派。每张隼鱼通常拥有比同稀有度更强的成长、经济或机制效果，但会附带负面条件：如果当天没有继续钓鱼、没有出售鱼、没有达到位置要求、金币不足、价值过高或结算前没有完成指定目标，就会损失金币、价值、售价、成长机会，甚至把收益转移给其他鱼。这个流派鼓励玩家主动做选择，而不是被动等待每日成长。

### 流派公共约定

- `falcon` 指所有 `archetype` 为 `falcon-risk` 的鱼卡。
- “猎标”是一种临时目标标记，通常指价值最高、价值最低、刚进入水族馆、刚出售或刚获得价值的鱼卡。猎标默认持续到当天结束。
- “俯冲”指一次高收益触发；如果俯冲条件不满足，通常会触发对应负面。
- “失衡”指隼鱼的负面条件触发，例如自身失去价值、金币减少、下一次钓鱼费用增加、或本次结算保留金币降低。
- “当天钓鱼过”指本日 `dailyCatchCount` 大于 0。
- “当天出售过”指本日通过鱼卡效果或出售动作卖出过鱼卡。后续代码实现时可通过每日计数记录。
- 隼鱼的负面效果应尽量可预判，避免随机直接毁局；高稀有度卡可以有更剧烈但可规划的代价。

## 后续实现提示

| 需求 | 建议触发点 |
| --- | --- |
| 记录当天是否钓鱼、出售、合成 | 每天开始重置每日计数；`onCatchStart`、`onFishSold`、`onCombineResult` 累加。 |
| 猎标标记 | `onDayStart` 写入临时字段，例如 `state.falconMarks` 或卡牌 `dailyCounters`。 |
| 条件负面 | 优先放在 `onDayStart`、`onCheckpoint` 或每日结束前统一结算，避免玩家无法理解。 |
| 保留金币 | 使用 `modifyCheckpointCoinRetention`。 |
| 修改每日金币上限 | 使用 `modifyBaseDailyCoinCap`，持续型效果需要记录结束天数。 |
