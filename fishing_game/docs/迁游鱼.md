# 迁游鱼图鉴

这个文件只记录“迁游鱼”种族的鱼卡。通用玩法、字段格式和跨种族索引见 [fish-card.md](fish-card.md)。

## 流派 002：九宫迁游

流派：`position-shift`

核心关键词：位置移动、换位、中心格、边角格、行列联动、移动次数、路径成长。

这个流派的核心不是单纯堆数量，而是让玩家围绕水族馆 3x3 的空间布局做构筑。鱼卡进入水族馆后通常不能手动移动，但“迁游鱼”会通过自身效果、同种族支援或特殊触发改变位置，并在移动、换位、进入关键格子、形成行列结构时获得价值成长。

### 流派公共约定

- 水族馆位置按 3x3 九宫格理解，从左到右、从上到下为 1-9。
- “中心”指第 5 格。
- “角落”指第 1、3、7、9 格。
- “边缘”指第 2、4、6、8 格。
- “相邻”默认指上下左右四方向，不含斜角。
- “移动”指鱼卡从一个格子进入另一个格子；“换位”视为参与换位的两张鱼都移动过。
- 如果目标格未解锁、被占用或不存在合法路径，则对应移动不发生，但其他非移动收益仍可正常结算。
- 同一天内的移动次数限制由单卡效果分别记录，防止无限循环。

## 初始平衡建议

- 迁游鱼强度依赖“可移动空间”，水族馆太早塞满时会降低部分效果收益。
- 这个流派适合和出售、空格、扩建、占 2 格鱼形成取舍，不建议让所有移动都无条件发生。
- 稀有卡可以提供换位和自动移动，但白绿卡最好只做小额移动收益，避免早期价值暴涨。
- 三星效果可以增加范围、次数或额外联动，但应继续保留每日触发上限。
- 这个流派需要 UI 对移动有明显反馈，例如鱼卡滑动、换位闪光、路径高亮，否则玩家不容易理解价值来源。

## 需要预留或补充的效果能力

| 能力 | 用途 |
| --- | --- |
| 获取鱼卡当前格子和九宫坐标 | 判断中心、角落、边缘、同行、同列、对角线。 |
| 获取合法相邻空格 | 支持自动移动和路径移动。 |
| 移动鱼卡到目标格 | 统一触发动画、日志、位置变化和 `onCardMoved`。 |
| 两张鱼卡换位 | 支持换巢鲤、万象换位鱼、星轨皇鲤等效果。 |
| 记录单卡本日移动次数 | 防止循环触发。 |
| 记录单卡本轮到达过的位置 | 支持九宫巡游鲷。 |
| `onCardMoved` 事件 | 支持移动后成长、同行同列支援、中心触发。 |
| `onFishSold` 事件携带空出格子 | 支持空位占星鱼。 |
| `modifyMoveReward` 触发点 | 允许鱼卡、角色或事件改变移动收益。 |
| 鱼卡移动和换位动画 | 让玩家看清位置流派的关键收益来源。 |
