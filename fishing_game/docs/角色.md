# 角色图鉴

这个文件记录当前可选角色和角色被动效果。之后新增角色、调整被动、替换头像或立绘，优先改这里，再同步到 `game-data.js`。

## 文档格式规范

每个角色建议固定记录这些字段：

```text
id：程序用唯一 ID。
名称：游戏内显示名称。
称号：角色选择界面显示的定位。
简称：角色卡片上的短名。
头像：头像资源路径。
立绘：立绘资源路径。
被动说明：玩家能直接看到的效果描述。
效果id：程序用效果 ID。
触发点：效果触发时机，例如 onDayStart、modifySellValue、modifyBaitPool、onCombineResult。
效果类型：对应 card-effects.js 里的效果处理器类型。
效果参数：具体数值配置。
备注：设计或平衡说明。
```

## 角色列表

### 阿潮

id：`tide`
名称：阿潮
称号：稳潮钓手
简称：潮
头像：`./assets/characters/tide-avatar.png`
立绘：`./assets/characters/tide-art.png`
被动说明：每天开始时获得 1G。
效果id：`tide-daily-coin`
触发点：`onDayStart`
效果类型：`gainCoins`
效果参数：`amount: 1`
备注：适合作为默认角色。因为第 1 天也会触发每日开始效果，所以阿潮开局会额外获得 1G。
