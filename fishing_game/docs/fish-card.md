# 大钓鱼鱼鱼卡图鉴索引

这个目录作为鱼卡设计的主文档区。之后新增鱼卡、调整数值、改效果，优先改这里，再同步到 `game-data.js` 和 `card-effects.js`。

## 游戏玩法概括

《大钓鱼鱼》是一款以“钓鱼三选一、水族馆养成、鱼卡合成、三日结算”为核心循环的肉鸽卡牌游戏。玩家每局从第 1 天开始经营水族馆，通过花费金币钓鱼获得鱼卡，再选择鱼卡放入水族馆格子中，让鱼卡通过自身效果、星级、流派联动和每日成长不断提高价值。

当前基础循环：

1. 玩家花费金币进行一次钓鱼。
2. 每次钓鱼会出现 3 张鱼卡，玩家通常选择其中 1 张。
3. 被选择的鱼卡需要放入水族馆的已解锁格子。
4. 水族馆初始不是 9 格全开，未解锁格子保留位置但不显示。
5. 水族馆内鱼卡位置通常固定，放入后不能随意移动。
6. 鱼卡可以出售换取金币，出售后空出对应格子。
7. 每三张相同鱼卡会自动合成 1 张更高星鱼卡，合成结果保留在第一张卡的位置。
8. 新的一天开始时，水族馆内鱼卡会获得自然成长，并触发各种鱼卡效果。
9. 每第三天结束时进行一次结算，水族馆总价值需要达到目标，否则本轮失败。
10. 每第三天结束后，如果通过结算，会自动获得一次水族馆格子升级选择。

鱼卡设计重点：

- 鱼卡不仅是分数来源，也是主要构筑来源。
- 每张鱼卡都应该有明确种族、流派、触发点和星级成长；基础通用鱼卡统一归入“杂鱼种族”。
- 鱼卡价值会被自身效果、其他鱼卡效果、角色被动、事件系统和星级共同影响。
- 鱼卡稀有度主要影响出现概率和边框颜色，不直接决定所有强度。
- 三星鱼卡应有更明显的成长价值，部分高稀有三星鱼可以提供特殊机制。
- 所有鱼卡效果应尽量服务于可重复游玩的构筑选择，而不是单次固定最优解。

## 当前基础数值

这些数值来自当前游戏配置和代码实现，后续调整时优先同步这里。

### 开局与金币

| 项目 | 当前数值 |
| --- | ---: |
| 初始金币 | 2G |
| 基础每日自动金币 | 4G |
| 基础每日自动金币成长 | 每经过 3 天，基础每日自动金币 +1G |
| 阿潮角色每日金币 | 新一天开始时 +1G |
| 基础钓鱼费用 | 3G |
| 每次钓鱼鱼获数量 | 3 张 |
| 基础可选择鱼获数量 | 1 张 |
| 基础卖鱼价格 | 通常 1G，部分鱼卡效果会修改 |

说明：基础每日自动金币在第 1 天开始时也会触发。第 1-3 天基础每日自动金币为 4G，第 4-6 天为 5G，第 7-9 天为 6G，以此类推。阿潮会在此基础上额外 +1G，所以阿潮第 4 天和第 5 天的新一天收入为 6G，第 7 天为 7G。每日金币还可以来自鱼卡效果或卖鱼。钓鱼费用、可选择鱼获数量和售价都预留了鱼卡效果修改。

| 水族馆总格子 | 3x3，共 9 格 |
| 初始解锁格子 | 4 格 |

| 项目 | 当前数值 |

饵料等级决定钓鱼时使用的稀有度池。稀有度概率可以被鱼卡、角色或事件效果修改。升级费用先计算基础费用和三日折扣，再经过 `modifyCoreUpgradeCost` 触发点，方便鱼卡或事件继续改变最终价格。

### 三日结算

每 3 天结束时触发一次结算，检查水族馆总价值是否达到目标。未达标则本轮失败，达标则可以继续，并进入结算后的水族馆扩建流程。

| 结算日 | 目标总价值 |
| --- | ---: |
| 第 3 天 | 24 |
| 第 6 天 | 60 |
| 第 9 天 | 110 |
| 第 12 天 | 180 |
| 第 15 天 | 270 |
| 第 18 天及以后 | 在上一档基础上每轮 +120 |

每次三日结算的前一天会给目标提醒。例如第 2 天会提醒第 3 天结束需要达到的目标。

### 鱼卡成长与合成

| 项目 | 当前数值 |
| --- | ---: |
| 默认每日自然成长 | `每日自然成长 x 星级` |
| 大多数鱼的每日自然成长 | 1 |
| 1 星默认每日成长 | +1 价值 |
| 2 星默认每日成长 | +2 价值 |
| 3 星默认每日成长 | +3 价值 |
| 合成条件 | 3 张同名同星鱼卡 |
| 合成结果 | 生成 1 张更高星鱼卡 |
| 合成位置 | 保留在第一张材料鱼卡的位置 |
| 最高常规星级 | 3 星 |

合成会把 3 张材料鱼的当前价值合并到结果鱼上，再触发相关合成效果。

## 文档格式规范

每张鱼卡建议固定记录这些字段，方便之后直接转成配置：

```text
id：程序用唯一 ID，使用小写英文和短横线。
名称：游戏内显示名称。
种族：游戏内详情页显示的种族；没有种族写“无”。
流派：流派 ID，例如 school-growth；没有流派写“无”。
稀有度：common / uncommon / rare / epic / legendary / mythic。
基础价值：初始价值。卡面底部显示的是经过效果修正后的当前价值。
基础售价：一般为 1G，特殊鱼可以例外。
占格：默认 1，特殊鱼可为 2 或更高。
标签：用于效果筛选，例如 school、growth、adjacent、combine；没有标签写“无”。
每日自然成长：默认每日自然成长值。大部分鱼可以为 1，特殊鱼可调整。
1星效果：基础效果。
2星效果：通常是数值小幅提高。
3星效果：通常是明显强化，或稀有卡获得额外特殊机制。
触发点：涉及的触发时机，例如 onEnterPond、onDayStart、onCombineResult、modifyCardValue。
```

## 稀有度分布建议

单个种族或流派目标约 18 张卡，默认分布：

| 稀有度 | 数量 |
| --- | ---: |
| 白 `common` | 2 |
| 绿 `uncommon` | 3 |
| 蓝 `rare` | 4 |
| 紫 `epic` | 4 |
| 橙 `legendary` | 3 |
| 红 `mythic` | 2 |

## 星级设计原则

- 1 星：表达卡牌的基础功能，数值克制。
- 2 星：保留原功能，数值略微提高，尽量不改变操作方式。
- 3 星：给明显成长点。白绿卡可以是更高数值；蓝紫橙红卡可以出现额外联动、范围扩大、触发次数提高或特殊效果。
- 三星鱼卡边框在游戏内显示为彩色，文档里不需要额外标注颜色。
